# DropIn 📍⚡️

> Spontaneous, proximity-based pickup sports matchmaking for university campuses.

Built during the Google AI Studio Hackathon by Martin & Pierre-Louis (ESSEC Business School @ UC Berkeley).

## The Problem
Spontaneity in recreational sports is broken. Organizing a simple casual game requires dead group chats or scheduling days in advance. People default to staying indoors.

## The Solution
DropIn turns the map into a live activity radar:
- **Instant Intent:** Broadcast your ready-to-play status in one tap.
- **Proximity Discovery:** Explore nearby tennis players, runners, and hoopers with real-time avatars and sport badges.
- **Safety & Trust:** Verified user badges, a dedicated "Women Only" filter, and an Uber-style post-match rating loop.
- **iOS 18 Liquid Glass UX:** Sleek, modern mobile-first interface designed for fast, frictionless matching.

## Tech Stack
- Frontend: HTML5, Modern CSS (Liquid Glass UI), JavaScript
- Mapping & Geospatial: Leaflet.js / OpenStreetMap
- Prototyping & AI Acceleration: Google AI Studio
